### Ettercap — GTK3 GUI bug fix

Contributed to [Ettercap](https://github.com/Ettercap/ettercap) by fixing a segmentation fault triggered when a PCAP file was not selected in the GTK3 graphical interface.

- **Pull request:** [#1335 — Fix segmentation fault after ignoring to select a PCAP file](https://github.com/Ettercap/ettercap/pull/1335)
- **Upstream status:** Merged into `Ettercap/ettercap`.
- **Release:** Included in [Ettercap 0.8.5.2 (Beccaria)](https://github.com/Ettercap/ettercap/releases/tag/v0.8.5.2).
