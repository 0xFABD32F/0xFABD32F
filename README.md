## About

I’m **Abdourahmane**, a software engineer interested in understanding how systems work and turning that understanding into practical, dependable software. My work and learning span backend and web development, C/C++ programming, algorithms, applied machine learning, and cybersecurity.

I enjoy investigating technical problems, thinking about performance and reliability, and contributing to software beyond my own projects. I value **clear design**, **maintainable code**, and **learning by building**.
